# demo/

`startseite.html` ist ein **statischer Auszug der Startseite** in einer einzigen Datei:
CSS, Schriften, Bilder und JavaScript sind eingebettet, es wird kein Server gebraucht.

Die Datei ist für schnelle Ansichten gedacht (z. B. über einen Link, der HTML aus dem
Repository rendert). Sie wird nicht von Hand gepflegt – nach Änderungen neu erzeugen
und nicht als Teil der Website veröffentlichen. Die echte Seite entsteht mit
`npm run build` in `dist/`.
